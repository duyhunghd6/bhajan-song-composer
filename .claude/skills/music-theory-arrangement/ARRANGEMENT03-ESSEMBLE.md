# Arrangement Module: Ensemble Expansion Engine

> **Scope:** This module expands a completed two-layer foundation — **Layer 1: Melody** + **Layer 2: Piano/Guitar Accompaniment** — into a full multi-instrument ensemble. It generates layers for **Djembe** (rhythm/percussion), **Flute** (melodic highlight), and **Violin** (harmonic bed/counterpoint).
>
> **Central Rule:** All auxiliary layers follow **Yield Logic** — they enhance the arrangement through rhythmic interlocking, frequency stratification, and counterpoint, but they must **never fight** the primary melody or accompaniment.
>
> **Accompaniment Setup Reuse:** The `/compose/:slug/accompaniment` setup can enable Djembe, Flute, and Violin before the later Ensemble step. In that context, reuse this module's Djembe interlock, Flute yield/breath, and Violin bed/expression rules through accompaniment branch steps (`djembe-groove-interlock`, `djembe-fill-validation`, `flute-yield-register`, `flute-breath-fill-validation`, `violin-bed-register`, `violin-expression-validation`). The later Ensemble workflow remains available for separate Layer 3 expansion and final conflict review.

---

## Role Summary

| Instrument | Accompaniment/ensemble role | Yield rule |
| ---------- | --------------------------- | ---------- |
| **Djembe** | Bass/Dum sync, Tone/Slap transient color, devotional groove interlock | Reinforce existing bass/transient events; soften or remove fills before disturbing melody/accompaniment. |
| **Flute** | High-register halo, breath-shaped gap fills, short melodic responses | Enter in rests/sustains and leave 16th-note breath gaps; never double or obscure the lead melody. |
| **Violin** | Warm harmonic bed, drone, counterline, expressive swells | Stay below/around melody unless explicitly featured; yield before Flute and Djembe fills in conflict review. |

## 1. Phase 0: Integration Handshake (Prerequisite Analysis)

Before generating any new notes, the system must analyze the existing foundation to determine safe rhythmic and frequency zones.

### 1.1 Grid Analysis

Scan Layer 2 (guitar/piano) to determine rhythmic density:

| Layer 2 Pattern | Density | Available Space for Ensemble |
| --------------- | ------- | ---------------------------- |
| Long block chords / whole notes | Low | Maximum — Djembe can be active, Flute/Violin have fill freedom |
| Arpeggiated 8th-note patterns | Medium | Moderate — Djembe syncs to downbeats only, Flute/Violin sustain |
| Busy 16th-note Travis picking | High | Minimal — Djembe holds basic groove, Flute/Violin freeze on pads |

### 1.2 Bass Map

Map the exact beat placement of the lowest frequencies generated by the guitar thumb or piano left hand. The Djembe bass tone must **sync** to these transients (see Phase 1).

### 1.3 Melodic Gap Array

Scan Layer 1 melody to identify:

- **Rests** (explicit `z` in ABC)
- **Sustained notes** longer than 1.5 beats (e.g., dotted quarter or longer)

These spans become **Fill Zones** — safe windows for Flute/Violin counter-melodies and optional Djembe fills.

## 2. Phase 1: Rhythmic Interlock — Djembe Layer

The Djembe layer stitches itself mathematically to the rhythmic topography established by Layer 2. It does **not** play independently — it reinforces.

### 2.1 Djembe Sound Palette

To simulate a realistic African Djembe on web platforms using standard General MIDI soundfonts, assign the track to **MIDI Channel 10** (Percussion) to leverage conga/bongo samples. Map the Djembe strokes to specific ABC pitch values that correspond to conga MIDI note numbers:

| Stroke | Technique | MIDI Instrument (Ch 10) | MIDI Note | ABC Pitch |
| ------ | --------- | ----------------------- | --------- | --------- |
| **Bass (Dum)** | Open palm, center of head | Low Conga | 64 | `E` |
| **Tone (Go)** | Fingertips, edge of head | Open High Conga | 63 | `_E` |
| **Slap (Pa)** | Sharp edge strike | Mute High Conga | 62 | `D` |

### 2.2 Bass-to-Kick Sync Protocol

Map the Djembe's **Bass** tone (`E`) exactly to the transients of the Layer 2 bassline:

```
If guitar thumb / piano LH plays root on beats 1 and 3:
  → Djembe Bass (Dum, E) fires simultaneously on beats 1 and 3
  → Fuses acoustic bass and drum impact into a single low-frequency event
```

**ABC Example:**
```abc
V:Djembe clef=perc name="Djembe" snm="Dj"
%%MIDI channel 10
K:C clef=perc
L:1/8
% E = Bass, _E = Tone, D = Slap
% Beat:  1  &  2  &  3  &  4  &
         E _E  D _E  E _E  D _E |
```

### 2.3 Subdivision Weave (Fill the Gaps)

Populate subdivisions that Layer 2 is NOT playing:

| Layer 2 Activity | Djembe Action |
| ---------------- | ------------- |
| **Downbeats occupied** by piano/guitar | Place low-velocity **Tone** (`_E`) taps on off-beats ("ands") |
| **Off-beats occupied** by syncopated comping | Place **Bass** (`E`) accents on downbeats only |
| **Continuous 8ths** from Layer 2 | Djembe holds minimal groove — Bass on 1, Slap on 3, rest elsewhere |

### 2.4 Backbeat Snap (Transient Matching)

Map the high-frequency **Slap** tone (`D`) to the backbeat (beats 2 and 4):

```
When guitar fingerstyle includes percussive string slaps:
  → Align Djembe Slap (Pa, D) with those events
  → Reinforces physical groove impact without conflicting transients
```

### 2.5 Djembe Groove Presets

#### Preset A: Bhajan / Devotional (Meditative)

## 3. Phase 2: Melodic Support — Flute & Violin Layers

Flute and Violin act as sustaining pads and counterpoint textures. Their job is to fill spatial and temporal voids while leaving the lead melody intelligible.

### 3.1 Frequency Stratification (Altitude Rule)

Each instrument occupies a distinct altitude in the frequency spectrum:

```
                    ┌─────────────────────┐
  C6 ───────────────│  Flute Halo (C5-C6) │  Airy, floating above
                    └─────────────────────┘
                    ┌─────────────────────┐
  C5 ───────────────│  Melody (C4-C5)     │  PRIMARY — never compete
                    └─────────────────────┘
                    ┌─────────────────────┐
  C4 ───────────────│  Violin Bed (G3-E5) │  Warm pad, interlocking
                    └─────────────────────┘
                    ┌─────────────────────┐
  C3 ───────────────│  Piano/Guitar (C2-C4)│  Layer 2 accompaniment
                    └─────────────────────┘
                    ┌─────────────────────┐
  C2 ───────────────│  Bass (C2-G3)       │  Foundation
                    └─────────────────────┘
```

| Instrument | Role | Register Constraint | MIDI Program |
| ---------- | ---- | ------------------- | ------------ |
| **Violin** | Harmonic bed / sustained pad | G3–E5 (below or interlocking with Layer 2 chords) | 40 (Violin) |
| **Flute** | Melodic highlight / halo | C5–C6 (octave above the primary melody) | 73 (Flute) |

### 3.2 Temporal Interlocking (Yield Logic)

The Flute and Violin operate in two states, switching based on Layer 1 melody activity:

#### State A: Yield / Background Mode (Melody is Active)

When Layer 1 has continuous melodic movement:

- Flute and Violin **freeze** into sustained chord tones from Layer 2
- Reduce velocity by ~20% (use `!mp!` or `!p!` dynamics in ABC)
- Hold long notes — do NOT create competing melodic motion

```abc
V:Violin clef=treble name="Violin"
V:Flute clef=treble name="Flute"
K:C
% Layer 1 is active — Violin and Flute sustain
[V:Violin] !mp!E4 | G4 |
[V:Flute]  !p!c'4 | e'4 |
```

#### State B: Fill / Foreground Mode (Melodic Gap Detected)

When the Melodic Gap Array exposes a rest or long held note:

- Flute and/or Violin play a short **secondary melodic run** bridging the singer's phrases
- The fill must use **scale tones** from the active chord
- Maximum fill duration: the length of the gap minus a 16th-note buffer

```abc
% Layer 1 rests for 2 beats — Flute fills
[V:Flute] !mf!c' d' e' f' | !p!g'4 |  % Fill then yield back
```

**Yield Rule:** The exact moment the primary melody resumes active movement, suppress fills immediately and return to Background Mode.

### 3.3 Anatomical Realism Validators

#### Flute Breath Validator

Real flute players need to breathe:

| Rule | Constraint |
| ---- | ---------- |
| **Forced rest** | Insert a minimum 16th-note rest (`z/`) every 2-4 measures |
| **Pre-breath velocity** | Reduce velocity on the note immediately before the breath mark |
| **Phrase length** | No continuous phrase exceeds 8 measures without a breath |

```abc
V:Flute clef=treble name="Flute"
K:C
L:1/8
% Note the breath rest at the end of phrase
c'd'e'f' g'2 z/ |  % Breath mark (16th rest)
```

#### Violin Bowing Automation

| Effect | MIDI CC | Rule |
| ------ | ------- | ---- |
| **Expression swell** | CC 11 | Apply slow crescendo on sustained notes (> 1 beat) |
| **Vibrato onset** | CC 1 | Delay vibrato until the note has been held for > 300ms |
| **Double stops** | — | Maximum 2 simultaneous notes; max stretch ~10th interval |
| **Bowing direction** | — | Alternate down-bow (strong beats) and up-bow (weak beats) |

## 4. Phase 3: Master Output & Conflict Resolution

Before outputting the final multi-layer ABC, run a conflict check across all vertical timeline slices.

### 4.1 Density Overload Check (Too-Busy Threshold)

Scan each beat position. If **all** of these are simultaneously active:
- Layer 1: Active melody
- Layer 2: Complex arpeggio or busy comping
- Djembe: Fast fill pattern
- Flute/Violin: Running fill

Apply the **Resolution Hierarchy** (highest priority wins):

```
1. Primary Melody      → ALWAYS wins, never modified
2. Layer 2 (Piano/Gtr) → Keeps its comping pattern
3. Flute / Violin      → Flattened into a sustained note
4. Djembe              → Fill removed, revert to base groove
```

### 4.2 Polyphony Validation

| Instrument | Max Simultaneous Notes | Action on Violation |
| ---------- | ---------------------- | ------------------- |
| **Flute** | 1 (monophonic) | Split into sequential notes |
| **Violin** | 2 (double stop) | Drop the lower note if stretch > 10th |
| **Djembe** | 1 (single strike) | Keep the most important tone (Bass > Slap > Tone) |

### 4.3 Frequency Masking Check

| Conflict | Resolution |
| -------- | ---------- |
| Violin overlaps melody register (C4-C5) | Shift Violin down to G3-C4 range |
| Flute overlaps melody register | Shift Flute up to C5+ range |
| Djembe slap masks guitar percussive hit | Reduce Djembe slap velocity by 30% |
| Bass frequencies muddy (< C3 with complex intervals) | Thin to roots, 5ths, and octaves only |

## 6. Validation Checklist

Before outputting any ensemble arrangement:

| Check | Rule |
| ----- | ---- |
| ✅ **Yield logic** | Flute/Violin in Background Mode when melody is active |
| ✅ **Fill zones only** | Counter-melodies only during Melodic Gap Events |
| ✅ **Frequency bands** | Each instrument in its assigned altitude (§3.1) |
| ✅ **Density cap** | No vertical slice has all layers simultaneously busy |
| ✅ **Resolution hierarchy** | Melody > Layer 2 > Flute/Violin > Djembe |
| ✅ **Breath marks** | Flute has rests every 2-4 measures |
| ✅ **Double stop limit** | Violin max 2 simultaneous notes, max 10th stretch |
| ✅ **Beat count** | All voices' beat counts match the time signature |
| ✅ **Djembe sync** | Bass tone aligned with Layer 2 bass transients |
